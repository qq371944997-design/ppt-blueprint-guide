## v1.0.0

Initial public release.

### Added

- Added `xgj-chatgpt-ppt.md` as the main guide.
- Added `PAGE_BLUEPRINT_USER_VIEW` to make slide planning visible before final build.
- Added `DESIGN_SYSTEM_SPEC` for fonts, typography scale, color palette, grid, chart style, and image treatment.
- Added `BUILD_RULES` to keep titles, body text, charts, diagrams, shapes, and numbers editable.
- Added `FINAL_BUILD_INPUT` to improve final PPTX generation stability.
- Added `Native Chart` rule for editable data charts.
- Added `SmartArt / Shapes / Connectors` rule for editable logic diagrams.
- Added CC BY-NC-SA 4.0 license.
- Added bilingual README.
- Added README hero image.

### Examples

- Added `examples/business-review.md`
- Added `examples/course-deck.md`
- Added `examples/xiaohongshu-card.md`
